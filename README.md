# GreenPulse 🌱

Hear what your street is saying.

GreenPulse is a community-powered dashboard that tracks air quality, noise, traffic and green spaces to help neighborhoods live healthier.

## Live Demo
https://greenpulse.netlify.app

## Features
- Real-time environmental metrics
- Interactive neighborhood map
- AI-powered community suggestions
- Mobile responsive, zero dependencies
